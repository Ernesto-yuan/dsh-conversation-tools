# 对话工具 / Conversation Tools

给 DeepSeek Harness 的对话界面加四件事：会话内查找、上键取回历史消息、复制对话里的图片、重新生成 / 继续生成。

## 功能

- 查找聊天记录：输入框左侧放大镜，或 Ctrl/⌘ + F 打开；查找条浮在输入框正上方（不占布局，打开时不会把对话顶上去，宽度跟输入框对齐）。窄条、有匹配计数、上一处/下一处和关闭按钮。输入即列出命中，回车跳到下一处；鼠标悬浮某条结果，面板侧边浮出全文卡片（可滚动），卡片底部有【复制整条】按钮，复制后显示“已复制”，Esc 关闭。
- 上键取回：输入框为空时按 ↑ 取回最近一条发过的消息，继续按 ↑ 往前翻，↓ 往回走；只接管富文本输入框，不影响其它输入。消息里的附件（图片、文件）会一起恢复成输入框里的草稿，翻到另一条时上一批草稿会被替换掉。
- 复制图片：鼠标悬浮对话里的任意图片，右上角浮出【复制图片】，点一下把这张图以 PNG 写进剪贴板，可以直接粘到聊天工具或文档里；成功显示“已复制图片”，失败显示“复制失败”。小于 56 像素的图片（图标、表情）不接管。
- 重新生成 / 继续生成：每条已完成的回答下方操作行多两个按钮。「重新生成」重发这条回答对应的提问（会替换输入框内容）；「继续生成」只在最新一条回答上出现，发送“继续”。

## 安装

需要包含 `conversation.*` 与 `chat` 插槽的 DSH 版本（已在 0.2.1-rc.2 验证）。

方式一：在 DSH 会话里让 Agent 用平台安装入口安装解压后的目录：

```
plugin_manager install_bundle <解压目录绝对路径>
```

方式二：命令行

```bash
dsh plugin --profile <你的 profile> add <解压目录>
```

安装后重启 DSH（或在 设置 → 插件 里确认已启用）。

## 说明

- 全是客户端功能，不写文件、不发网络请求。
- 复制图片走浏览器的图片剪贴板接口，只在 localhost 或 https 页面可用；复制时会按图片字节写回，跨域图片读不到字节时改用画布栅格化，仍失败就提示“复制失败”。
- 查找面板只在当前会话已加载的消息里搜索；跳转依赖聊天区每条消息的 `data-chat-node-key` 属性，尚未分页加载的消息点不到。
- 「重新生成」是重新发一轮，不会删除原来的回答。
- 上键历史只覆盖当前会话已加载的消息；附件按原字节重新读回，单条最多恢复 6 个，读取失败的会被跳过。
