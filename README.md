# 对话工具 / Conversation Tools

给 DeepSeek Harness 的对话界面补上三件常用工具：会话内查找、上键取回历史消息、重新生成与继续生成。

## 功能

### 会话内查找

- 输入框左侧的放大镜按钮，或 Ctrl/⌘ + F 打开。
- 查找条浮在输入框正上方，宽度与输入框对齐，不占布局，打开时不会把对话顶上去。
- 输入即列出命中并显示命中计数；回车跳到下一处，另有上一处 / 下一处按钮，Esc 关闭。
- 鼠标悬浮某条结果，面板侧边浮出可滚动的全文卡片，底部【复制整条】一键复制该消息，复制后显示【已复制】。

### 上键取回

- 输入框为空时按 ↑ 取回最近一条发过的消息，继续按 ↑ 往前翻，↓ 往回走。
- 消息里的图片和文件附件一并还原成输入框草稿；翻到另一条时，上一批草稿会被替换。

### 重新生成 / 继续生成

- 每条已完成的回答下方多出【重新生成】，点击会重发这条回答对应的提问。
- 最新一条回答额外多出【继续生成】，点击发送“继续”。

## 安装

推荐从 npm 安装：

```bash
dsh plugin --profile <你的 profile> add dsh-conversation-tools
```

也可以直接从本仓库安装：

```bash
dsh plugin --profile <你的 profile> add github:Ernesto-yuan/dsh-conversation-tools
```

或下载 Release 里的 tgz：

```bash
dsh plugin --profile <你的 profile> add <tgz 文件路径>
```

装完在 设置 → 插件 里确认已启用。客户端代码首次加载需要刷新页面。

## 兼容性

已在 DSH 0.2.1-rc.3 上验证。

## 说明与限制

- 纯客户端实现：不写文件、不发网络请求、不读取会话存储以外的数据。
- 查找只覆盖当前会话已加载的消息，未分页加载的部分搜不到。
- 点击结果只做选中，不做跳转。聊天区是虚拟列表，未挂载的消息无法定位；需要完整内容时用悬浮卡片的【复制整条】。
- 上键历史只覆盖当前会话；单条消息最多恢复 6 个附件，读取失败的附件会被跳过。
- 【重新生成】是重新发一轮，不会删除原来的回答。
